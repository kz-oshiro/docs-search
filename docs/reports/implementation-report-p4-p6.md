# P4a〜P6の実装報告

作成日: 2026-10-03。対象: [追加機能計画](../plans/implementation-plan.md)の残り4段階すべて。
コード・仕様・確認方針を作業ツリーに追加した。新しい機能の動作確認・公開完了を示す報告ではない。

## 変更した挙動

- P4a: Excelの保存式を保存値と別に検索し、共有式の保存された基点と情報を表示する。PowerPointのノート本文をスライド・図形・段落で返し、番号等のプレースホルダーを除く。
- P4b: Excelの従来・スレッドコメント、Wordヘッダー・フッター・コメント内の段落と表を検索する。共有Word部品と取得済みコメントに対応するVMLを重複させない。
- P5: `ranking.rs` が一致品質、充足語数、同じ行、本文、上限付きの異なる根拠数を比較し、理由と結果ID順を通知する。GUIの重複した順位規則を除いた。CLIとJSONにも同じ根拠が渡る。
- P6: 1回の列挙・ファイル抽出で最大256語を一括検索する。識別子境界または通常の文字列検索を選び、語別件数・確認状態、詳細、語×ファイル表とCSV/TSVを利用できる。

`includeNotes` と `includeFormulas` は初期値・省略値ともオフ。通常・条件・一括すべてで利用できる。注記の部分障害では本文を保持し、不完全なファイルで条件成立や索引確定をしない。索引の抽出仕様版を3にし、注記/数式の範囲ビットで再利用を判定する。元文書を書き換えず、数式/コードを実行せず、外部参照を取得しない。

## 主な変更先

- `core/src/extract.rs`、`index.rs`、`query.rs`、`context.rs`、`lib.rs`、`main.rs`: 抽出、部分障害、索引、行判定、周辺取得、通知、CLIフラグ。
- `core/src/batch.rs`、`ranking.rs`、`report.rs`: 入力検証・識別子一致、順位集約、語別/行列出力・JSON拡張。
- `frontend/`、`src-tauri/src/main.rs`: 入力、事前件数、追加場所表示、順位、語別詳細/行列、保存連携。
- `tests/fixtures/generate-office-search-fixture.py`、`tests/cli/run-office-search-cases.py`、`scripts/Run-Local-CI.ps1`: 独立した固定データとCLI確認。既存共通27ケースの生成器・期待値は維持。
- `docs/specifications/requirements.md`、`backend.md`、`boundary.md`、`gui.md`、`implementation-status.md`、各README: 仕様・契約・操作・進捗・次の確認。

## 静的確認と未実施

Rustはrustfmtによる構文解析と整形、インラインJavaScriptはNodeの構文確認、追加Python2本はAST解析、ローカルCIスクリプトはPowerShellの構文解析を実施した。HTMLのID重複・ラベル/コードからの参照・ソース資産、関連文書10本のローカルリンク、差分と追加ファイルの末尾空白も静的確認し、問題がないことを確認した。型検査・実行検証は含まない。

テスト、cargo check、WASM/Windowsビルド、生成器の実行、アプリ起動、GUI、コミット、push、リリースは未実施。作業ルールに従い、これらは次の依頼範囲として残す。現在の既存exeと公開済みv2.0.7には今回の変更はまだ含まれない。

## 次の担当への引き継ぎと制限

[確認方針](../test-plans/office-ranking-batch-test-plan.md)に確認項目・手順・期待結果をまとめた。テスト・ビルドの依頼時はPowerShell回帰→更新したローカルCIの順で実行する。GUIだけは明示依頼または事前確認を必要とする。ユーザーにテスト全体の実施を依頼しない。

- 一括検索の索引経路は全Unitを1回読み込む方式。候補による省略は行わず、検索漏れを避ける。大規模文書×256語の時間/メモリは未測定。
- 数式を再計算・再構成しない。保存文字列にない共有従属式や未保存値は検索しない。
- Wordの部品種類・コメントIDは取得するが、コメントから元本文へのジャンプを保証しない。共有部品の種類は最初の参照を表示する。
- 索引に注記/数式を含めた検索から周辺表を開く場合、周辺表の索引が通常範囲として有効でなければ元Excelを読み直す。周辺表示は保存値だけである。
- 語別一覧は全検索の件数。絞り込みはファイル一覧/出力に適用する。行列出力には全語、選択対象のファイル、全検索の確認状態と出力範囲を記録する。
- 20クエリの旧順位比較は、同じヒット集合に旧GUIの規則を適用したもの。旧バイナリによる実測とは区別する。
- 新旧設計書の差分表示は元計画の対象外。
