# docs-search v2.0.6

Windows x64 向けの実行ファイルです。

## 変更点

- 検索結果に「一致検索」「あいまい検索」を表示し、読み取り・列挙エラーの種別、対象パス、理由を確認しやすくしました。
- 検索終了後に、全結果または現在の絞り込み結果を TSV で一括コピー、CSV/TSV で保存、JSON の調査記録として保存できるようにしました。
- Excel セルの行・列、検索単位とグループの識別情報を追加し、ローカル索引へ保存します。旧形式の索引は元文書から再構築します。

## 確認結果

- PowerShell 実装のテスト、共通バックエンド 27 ケース、Rust 13 テスト、WASM チェック、Windows 実行ファイルのビルドに成功しました。
- Excel の同じ検索結果と件数が、索引なし・索引初回作成・索引再利用で一致することを CLI で確認しました。
- GUI 操作の確認は実施していません。
