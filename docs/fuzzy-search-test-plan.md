# あいまい検索の確認方針

実装後のテスト担当者はこの方針を読み、既存の共通ケースと追加ケースを実行する。検索用索引とあいまい検索は独立したチェックボックスで、初期状態は両方オフ。あいまい検索の各項目ではチェックをオンにする。索引オンの初回検索と2回目以降を分けて確認する。GUI テストを実施する場合はリポジトリの `AGENTS.md` に従う。

| 確認項目 | 手順 | 期待結果 |
| --- | --- | --- |
| 初期値と通常検索 | 新しい画面で両方のチェックが外れていることを確認し、`fuzzy/variants.md` を `顧客ID` で検索 | 7行目の1件だけ。8行目の幅差、9行目の空白差は出ない。既存の索引があっても読み書きしない。 |
| オプションの独立性 | 索引オフ・あいまい検索オン、索引オン・あいまい検索オフ、両方オンを順に選び、同じ文書を検索 | 索引オフでもあいまい検索の候補が出る。索引オンでもあいまい検索がオフなら通常検索の結果だけ。両方オンなら候補が出る。索引オンの結果は初回と再検索で一致する。 |
| 識別子 | `customerId`、`CustomerId`、`CUSTOMER_ID`、`customer_id`、`customer-id`、`customer id` を別セルに置き、`customerId` で検索 | 6セルが各1件。原文・大小差が区切り差より上位で、強調範囲が原文の識別子を指す。 |
| 全角半角・空白 | `顧客ID`、`顧客ＩＤ`、`顧客 ID` を検索 | 3セルが各1件。順に完全一致、正規化、区切り差の理由となる。 |
| タイプミス | `customer` と `custmer` を置き、`customer` で検索 | 前者が上位。後者はタイプミス候補として出る。 |
| 短語の誤爆 | `ID`、`NO`、`CODE`、`1/2`、`12`、`1.0`、`10`、日本語1～2文字を別セルに置く | 編集距離による別語への一致がない。`1/2` と `12`、`1.0` と `10` を同一視しない。 |
| Unicode と強調 | 結合文字、半角カナ、ひらがな・カタカナを置く | 対応する検索で原文上の範囲が強調され、表示文字列は変わらない。 |
| 検索単位 | 同一セルに検索語を複数回、別セルにも1回、ファイル名にも1回置く | 同一セルは1件、別セルとファイル名は別件。`resultCount` は通知件数と一致する。 |
| 索引更新 | 索引をオンにして初回検索後に再検索し、元ファイルを更新・削除して再検索。索引をオフにして再検索し、保存済みの索引の更新日時・容量も確認 | 索引オンでは未変更ファイルを再抽出せず、更新内容が反映され、削除ファイルは結果に出ない。オフでは索引に変更を加えず文書を読み直す。索引削除後もオフなら再作成せず、オンにした次回検索で再作成する。 |
| エラー・中断 | 読めないファイルを混ぜ、検索中に中断する | 個別エラーを表示し、通知済み結果を維持する。終了集計と通知件数が一致する。 |
| 負荷 | `tests/README.md` の load データと多数セルの Excel で初回・再検索・短語検索を測る | 編集距離を全セルに適用せず、再検索が抽出処理を再実行しない。検索中も中断と画面操作が可能。索引容量と所要時間を記録する。 |

静的確認では `git diff --check` と仕様・コード・結果ラベルの対応を確認する。自動テストのみの依頼では、リポジトリルートから `powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\tauri\Run-Automated-Tests.ps1` を使う。共通ケース、Rustテスト、WASM型検査、試験用WASM生成とヘッドレスPlaywrightを含む。Windows配布ビルドまで依頼された場合は、この入口に代えて `powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\tauri\Run-Local-CI.ps1` を使う。

チェックボックスの初期値・要求オプション・理由ラベル・強調・完了後の並べ替え・索引削除のブラウザー内状態は [Playwright方針](playwright-ui-test-plan.md)の自動項目で確認する。実アプリのOS連携・見た目はM1〜M5に従い、明示依頼または事前確認がある場合に実施する。

一致区分とエラー欄の表示確認は [結果ラベル・エラー表示の確認方針](./result-match-error-test-plan.md) を参照する。
