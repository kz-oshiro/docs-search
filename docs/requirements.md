# docs-search 再構築版: 全体要求仕様

状態: 技術に依存しない要求仕様。Tauri 実装の方式と実行方法は [Tauri 実装の README](../tauri/README.md) を参照。

## 目的と対象

利用者が指定した1つ以上のローカルフォルダー以下の文書から語句を探し、どのファイルのどこにあるかを確認できるようにする。Office 文書とテキスト系の計93拡張子に対応し、検索ごとに対象を選べる。対応一覧と検索対象・除外対象の詳細は [バックエンド仕様](./backend.md) に定義する。

旧 PowerShell 実装は [別ディレクトリ](../powershell/README.md) に保存する。Tauri 実装は旧実装のコード構造や PowerShell / Windows Forms に依存しない。機能の基準はこの文書群であり、旧実装の偶然の挙動を無条件に引き継がない。

## 基本的な利用の流れ

1. 利用者が検索フォルダーを1つ以上指定し、必要なら対象外フォルダーも指定する。検索語と対象拡張子を選んで検索を開始する。
2. 対象ファイルを列挙して読み取り、見つかった場所を順次表示する。
3. 読めないファイルがあっても、他のファイルの検索を続け、失敗したファイルを示す。
4. 利用者は結果から元ファイルを開くか、場所をコピーする。検索終了後は全結果または現在の絞り込み結果を一括コピー・保存できる。処理中は中断できる。
5. 終了時は「完了」「中断」「全体失敗」を区別し、結果件数、検索したファイル数、エラー件数を示す。

## 設計上の責務

| 領域 | 責務 | 詳細 |
| --- | --- | --- |
| GUI | 入力、状態と結果の表示、開く・コピーする操作 | [GUI 仕様](./gui.md) |
| 検索バックエンド | 列挙、形式判定、内容抽出、照合、進捗とエラーの報告 | [バックエンド仕様](./backend.md) |
| 両者の境界 | 要求、結果、進捗、終了、中断の意味と順序 | [境界契約](./boundary.md) |

境界は関数呼び出し、プロセス間通信、その他の実装手段に置き換えられる。ファイルを開くこととクリップボードへのコピーは GUI 側の操作とし、検索バックエンドはそのためのファイルパスと場所情報を返す。

## 初期版で扱わないもの

- `.xls`、`.ppt`、`.doc`、PDF、画像、OCR、クラウド上の文書専用 API。
- 正規表現、括弧を使う論理式、検索結果の編集、置換、ファイル内容の更新。
- 検索履歴、ユーザー文書のアップロード、外部検索サービス。
- 文書内の数式・マクロ・埋め込みプログラムの実行、外部リンクの取得。

将来形式を追加できる構造は求めるが、上記の形式を初期版で「検索できる」と表示してはならない。

## 非機能要求

- 検索中も GUI の入力・中断・結果閲覧が操作可能であること。大量の結果を一度に画面へ反映して応答不能にしない。
- 読み取り専用で動作し、対象文書やフォルダーに索引・一時ファイル・履歴を書かないこと。検索用索引はユーザーのローカルアプリ領域へ保存し、削除できること。元文書を検索処理から起動しないこと。
- 対象の破損・巨大な入力・外部参照を含む文書を安全に扱い、ファイル単位の失敗を隔離すること。
- 検索開始から終了まで件数と状態を一貫して報告し、部分的に失敗した検索を成功のみとして見せないこと。
- 処理時間やメモリ使用量の具体的な上限値は、対象端末とデータ量を決めてから性能試験の合格値として定める。現段階で数値を推測して固定しない。

## 受け入れ条件

| ID | 確認事項 | 期待結果 |
| --- | --- | --- |
| A-01 | 対応拡張子を含む入れ子のフォルダーを検索 | 選択した拡張子だけを列挙し、各形式の定義済み箇所を見つけられる |
| A-02 | 大文字と小文字が異なる検索語、語句を含む長い文 | 原文の一致と大文字・小文字差を優先し、部分一致を結果として返す |
| A-03 | 同じ語句が別セル、別スライド、別段落、別行にある | 場所を区別した結果を返す |
| A-04 | 壊れたファイル、アクセス拒否、検索中の削除 | 個別エラーを表示し、読める残りのファイルを処理する |
| A-05 | 検索中に中断 | 中断したと表示し、既に得た結果とエラーを残す |
| A-06 | 結果から元ファイルを開く、場所をコピー | 正しいファイルと識別可能な場所を利用者へ渡す |
| A-07 | 空の検索語、存在しないフォルダー | 検索を開始せず、入力欄に対応したエラーを示す |
| A-08 | 大量の対象ファイル・結果 | 進捗と中断が操作でき、完了時の件数が実際の通知と一致する |
| A-09 | 同一の検索契約を別の GUI / 実装に接続 | GUI 固有オブジェクトや内部ライブラリの型を境界に要求しない |
| A-10 | 拡張子を1種類または複数種類選択して検索 | 選択した拡張子のファイルだけを処理し、未選択の形式は結果・エラー・件数に含めない。選択なしは入力エラーにする |
| A-11 | 複数の検索フォルダーと対象外フォルダーを指定 | 指定した検索フォルダーをまとめて検索し、対象外の配下は列挙しない。検索フォルダーが重なっても同じファイルを二重計上しない |
| A-12 | 検索終了後に全結果・絞り込み結果を一括出力 | 画面で未描画の結果も対象に含み、選んだ対象の件数と出力行数が一致する。調査記録には検索条件、終了状態、集計、Issue を残す |
| A-13 | Excelの行情報を含む検索単位を直接読み取り・索引再利用で確認 | 同じシートの同じ物理行は同じグループ、別シート・別行は別グループとなり、結果の件数・場所・一致方式は同じ。結合範囲は検索件数を増やさない |
| A-14 | Excel のセル一致から周辺セルを開き、列方向に移動 | 初期表示は一致位置を含む最大5×5。遠い列へ送れて、保存済み値、空欄、結合範囲と起点、非表示行・列、シートと番地を区別できる。索引有無で同じ内容になり、ファイル変更・削除時は再検索を促し、結果を残す |
| A-15 | 高度な検索で AND・OR・除外語と判定範囲を指定 | 同じ検索箇所、Excel の同じ物理行、同じファイルを区別し、各結果に成立した語句と場所を示す。除外語は指定範囲全体で判定し、索引の有無・あいまい検索の有無で意味が変わらない |

## 要決定事項

以下は利用者の要求から確定できないため、実装前に決める。

- 対応 OS と配布形態。ファイルを開く操作はその環境の既定アプリに委ねる。
- 性能試験の端末、データ量、許容時間、メモリ上限。
