# docs-search 再構築版: GUI 仕様

この文書は利用者に見える操作と表示を定義する。レイアウトの寸法、色、GUI フレームワークは指定しない。[全体仕様](requirements.md)と[境界契約](boundary.md)を併せて参照する。

## 入力と操作

| 要素 | 要求 |
| --- | --- |
| ウィンドウタイトル | Windowsのタイトルバーに `docs-search vX.Y.Z` を表示する。`X.Y.Z` はビルドした製品版から取得し、配布EXE名の版と一致する。EXEを改名しても表示する版は変わらない。 |
| 設定: テーマカラー | 設定からサンオレンジ（デフォルト）・アンバー・夕焼け・青緑・ブルー・フォレストの6色を選べる。変更は検索中も即時反映し、次回起動時に復元する。保存できない環境では現在の起動中だけ適用し、その旨を設定内に示す。 |
| 検索方法と検索語の配置 | フォーム上段に検索方法、その右に通常検索の検索語を配置し、検索フォルダ欄は次の行で横幅を使う。検索方法の幅は最も長い選択肢・開閉矢印・余白に合わせ、切替時にも安定させる。残りの幅を検索語欄に使い、狭い画面では検索方法→検索語の順に縦へ並べる。Tab移動順も表示順に合わせ、高度な検索・一括検索では通常の検索語欄を隠す。 |
| 検索フォルダ | 「追加」で複数のフォルダを指定できる。各欄でパスの入力・貼り付けとフォルダ選択ができ、追加した欄は削除できる。検索操作時は他の入力検証より先に空欄・空白だけの欄を取り除き、入力済みの順に検索する。主欄が空なら最初の入力済みパスを主欄へ移す。全空欄なら編集できる主欄を1つ残し、指定を促して検索を止める。入力済みの無効パスは保持し、存在するフォルダを必須とする。 |
| 対象外フォルダ | 「追加」で任意の件数を指定できる。各欄でパスの入力・貼り付けとフォルダ選択ができ、欄を削除できる。指定したフォルダの配下は検索対象に含めない。 |
| 検索フォルダの履歴 | 主・追加欄の「履歴…」から最近使った検索フォルダを選ぶ。操作した欄だけへ反映し、選択だけでは検索しない。個別削除・全件削除とキーボード操作ができる。対象外フォルダは履歴へ含めない。 |
| 検索語 | 通常検索では1件の文字列を入力する。前後の空白を除いた後に空なら検索を開始しない。AND / OR という文字も1語句の一部とする。 |
| 高度な検索 | 検索方法を切り替え、「すべて含む」「いずれか含む」「含まない」の各欄に1行1語句で入力する。判定範囲は同じ検索箇所・Excelの同じ行・同じファイルから選び、初期値をExcelの同じ行とする。 |
| 検索する拡張子 | 対応する93拡張子を用途別の分類から複数選択できる。全体と分類ごとに一括選択・解除でき、選択数が分かる。初期状態では対応する93拡張子をすべて選択する。1種類も選ばれていなければ検索を開始せず、理由を示す。 |
| 検索 | 有効な入力で 1 回の検索を開始する。同じ画面で並行して複数検索は行わない。 |
| 結果の絞り込み | ファイル名・パス・拡張子・Excelのシート名と、本文に含む語句・含まない語句で一致箇所を絞り込める。解除すると再検索せず全結果へ戻る。 |
| 中断 | 検索中に使用できる。要求後は「中断中」と表示し、終端通知を受けるまで待つ。 |
| ファイルを開く | 各ファイルのファイル名リンクから元ファイルを既定アプリで開く。文書内の位置への自動ジャンプは保証しない。ファイルが移動・削除されていた場合は説明する。 |
| 場所をコピー | 各一致箇所のコピーアイコンから、その結果の絶対パスと場所を人が読める形でコピーする。 |
| 結果を一括出力 | 検索終了後、全結果または現在の絞り込み結果を選び、TSVのコピー、CSV/TSVの保存、JSON調査記録の保存を行う。 |

検索・対象外フォルダの入力をWebViewの `localStorage` の `docs-search.folders.v1` に保存し、同じアプリ・ユーザープロファイルの次回起動時に欄数と順序を復元する。入力・追加・削除・参照選択と検索時の空欄整理のたびに更新する。整理後は表示中の欄だけを同じ順序で保存し、全空欄時は空の主欄1つを保存する。復元時はデスクトップ層で絶対パスのフォルダ存在を確認し、無効な欄だけ空欄にする。保存値の破損や保存不可でも起動でき、入力を修正できる。保存不可時は通知する。復元確認中は検索開始を無効にし、検索は利用者の操作で開始する。バックエンドはフォルダ選択、元ファイル起動、クリップボード操作を担当しない。
テーマカラーは画面の見た目の設定であり、検索条件・結果・絞り込み・索引へ影響しない。エラー、警告、一致区分、ファイル形式の意味を示す色とラベルはテーマによらず維持する。保存値が未設定・不正な場合はデフォルトのサンオレンジを使用する。以前に保存した有効な色は継続して復元する。アプリアイコンは白い書類と茶色の虫眼鏡を組み合わせたサンオレンジの公式ロゴで、画面テーマを変更しても固定する。確認方針は [テーマ設定の確認方針](../test-plans/theme-settings-test-plan.md) を参照する。
検索フォルダが重なる場合は同じファイルを重複表示しない。対象外フォルダは検索フォルダの指定より優先する。空欄整理は検索ボタン・Enterと通常・高度・一括の検索方法で共通とする。整理後の欄はラベル・参照・削除・Tab順を揃え、「追加」で再び増やせる。存在しないフォルダ、全空欄の検索フォルダ、空の対象外フォルダ欄があれば、対応する欄の近くに理由を示して検索を開始しない。

「参照…」は操作した検索・対象外フォルダ欄の現在値をデスクトップ層へ渡す。存在するフォルダならそのフォルダ自体を開始位置にし、空欄・存在しないパス・ファイルなら実行ファイルの親フォルダ、取得できなければダイアログ既定値へ戻す。手入力と復元値を同じように扱い、開始位置の判定では入力を変更しない。選択確定時は操作した行だけ更新・保存し、取消時は保持する。

### 検索フォルダの履歴

検索フォルダだけの共通履歴を、WebViewの `localStorage` の `docs-search.folder-history.v1` に文字列配列として保存する。既存の入力保存キーは変更せず、起動時の入力復元から履歴を自動生成しない。全件削除した履歴が再起動で復活することを防ぐ。記録するのは次の操作が確定した時点とする。

- 検索フォルダの参照ダイアログでパスを選択したとき。取消・空欄・参照失敗・対象外フォルダの選択は記録しない。
- 履歴のフォルダを再検証して入力へ反映したとき。
- 検索の入力検証が成功して、現在の検索のStartedを受信したとき。手入力・貼り付けを含む主/追加フォルダを要求順に先頭へ並べ、対象外フォルダは記録しない。入力途中・入力拒否・旧検索の通知では記録しない。

最近使った順に20件まで保持し、上限超過時は最も古いものから除く。重複の比較では前後空白・Windowsの大文字小文字・スラッシュ/バックスラッシュ・末尾の区切り・絶対パスの `.` / `..`・ドライブ/UNCの拡張長パス接頭辞を吸収する。表示と入力には直近に確定した元の表記を使う。別名の共有・ジャンクション・短いファイル名などの物理的同一性は判定しない。

履歴画面ではフルパスを折り返し、同名の別フォルダを区別する。TabとEnterで選択・削除でき、Escape/閉じるで元の履歴ボタンへ、選択後は反映した入力欄へフォーカスを戻す。個別削除・全件削除は履歴だけに作用し、現在の入力や実際のフォルダを変更しない。

選択時は既存の `validate_folder_paths` で絶対フォルダの存在を再確認する。無効・検証失敗は履歴画面へ対象パスと理由を示し、入力は保持する。無効履歴を勝手に消さず、利用者が削除できる。確認中の二重操作を防ぎ、取消後や入力変更後に返った応答を反映しない。選択後の検索では通常の最終入力検証を引き続き行う。

不正JSON・配列以外は履歴なしとして起動し、非文字列・空文字・NULを含む要素・重複・上限超過は除いて読み込む。保存値の問題と保存不可を通知し、通常の入力・参照・検索を妨げない。保存できなくても起動中の履歴は利用できる。確認方針は[フォルダ履歴の確認](../test-plans/playwright-ui-test-plan.md#フォルダ履歴の確認34)を参照する。

## 結果一覧

検索結果を絶対パスで識別した親フォルダごとにまとめ、その配下にファイル単位の結果を並べる。同名の別フォルダは混同しない。各フォルダとファイルに独立した折りたたみ・展開ボタンを置き、初期状態は展開済みとする。ボタンはキーボードで操作でき、対象のラベル・`aria-expanded`・`aria-controls`を持つ。ファイル名リンクによる元ファイル起動は別操作である。

フォルダ見出しはパス・絞り込み後のファイル数・一致件数・エラーのあるファイル数を保持する。未描画のファイルも件数に含む。ファイル見出しは絞り込み後/全体の一致件数・名前・パス・拡張子・エラー状態・更新日時を保持する。日時は検索時点のファイルシステムの最終更新時刻を `YYYY/MM/DD HH:mm:ss` と端末のタイムゾーン名（例 `Asia/Tokyo`）で示す。取得できなければその状態を示し結果を残す。

ファイルを折りたたむと一致箇所・抜粋・根拠・周辺表を隠す。フォルダを折りたたむと配下のファイルを隠す。追加通知、完了/中断の並べ替え、絞り込みと解除、追加ページでも両階層の状態を独立して保持し、新しい検索では展開済みへ戻す。結果データや件数を減らさず、一括出力にも折りたたみを適用しない。

検索結果はファイルごとに1つのまとまりで表示し、同じファイルの一致箇所をその下に並べる。ファイルの見出しには一致件数とファイル名のリンクを示し、クリックで元ファイルを開けるようにする。拡張子はファイル名の左に色付きのタグで示し、ファイルパスはファイル名の下に小さめの灰色の文字で表示する。各一致箇所には文書内の場所、該当文字列を含む抜粋、場所をコピーするアイコンを置く。抜粋内の一致箇所は背景色などで強調し、文字を読める状態に保つ。抜粋は一致箇所が分かる文脈を含め、長い内容を省略する場合は省略したことが分かる表示にする。ファイル名一致も結果として表示する。場所の表記例は以下のとおり。

| 形式 | 場所の例 |
| --- | --- |
| Excel | `Sheet1!C12`、`Sheet1 / 図形名` |
| PowerPoint | `スライド 3 / 図形名` |
| Word | `本文 段落 12`、`表 2 / 行 3 / 列 1` |
| テキスト・ソースファイル | `行 42` |
| ファイル名 | `ファイル名` |

GUI は検索中にファイルを到着順で追加し、完了・中断時にコアの確定したファイル順位へ並べ替える。各ファイル内の一致箇所は追加時から `documentOrder` の位置順に並べ、スコアで順序を変えない。Excelはブック内のシート順・行数値・列数値・内容種別・抽出順、テキストは行数値、PowerPointはスライド順と抽出順、WordはXML本文内の段落と表の抽出順とする。同じ位置は語ID・検索単位ID・結果IDで安定させる。位置を取得できない図形・注記はシートまたは部品内の抽出順を使う。ファイル名一致は先頭、ファイル範囲条件は最初の位置の根拠を代表とする。親フォルダの並びは配下で最も上位のファイルの順位で決まり、同じ親の中ではファイル順位を保持する。ファイルごとに「3語に一致」「同じ行で2語に一致」「本文に根拠あり」などの順位理由を示す。GUI独自の順位計算は行わない。各一致箇所には「一致検索」（通常検索でも見つかる）または「あいまい検索」（あいまい検索オンで初めて見つかる）を文字と色の異なるラベルで示し、一致理由も短く添える。あいまい検索をオンにしていても、通常検索で見つかる検索単位には「一致検索」を表示する。数値スコアは表示しない。結果件数はファイル数ではなく一致箇所の件数とする。並べ替えや絞り込みでも元の結果と件数を失わない。結果が 0 件なら「該当なし」を表示し、読み取りエラーがある場合はその件数も併記する。検索用索引は端末内へ自動保存し、利用者が画面から削除できる。

結果の絞り込みは保持している全結果へ適用し、検索処理を再実行しない。ファイル名・パスと拡張子はファイルの条件で、本文に含む語句・含まない語句は一致箇所の条件である。語句欄は各1語句（空白も語句の一部）とし、NFC正規化と大文字・小文字を区別しない部分一致で判定する。本文の対象は表示された抜粋または各根拠の抜粋で、ファイル名・場所ラベル・全文や周辺セルは含めない。含む語句がある抜粋を1つ以上持ち、含まない語句がどの抜粋にもない一致箇所を残す。すべての条件を併用でき、1ファイル内の一部だけが成立すればその箇所だけを表示する。絞り込み中も全体の結果件数を変えず、表示対象のファイル数・一致件数と全体数を別に示す。検索中に届いた結果にも現在の条件を適用する。新しい検索を始めると条件を解除する。

「Excelのシート名」は各結果と根拠の構造化された `sheetName` に対する1語句の部分一致とし、NFC正規化と大小文字を区別しない規則を使う。指定中はxlsx/xlsmのうち該当シートを持つ一致箇所だけを残し、シート名のない結果や非Excelを除く。ファイル条件の結果は根拠のいずれかが該当すれば残し、成立済み条件や他シートの根拠を削らない。本文・ファイル名・場所ラベルからシート名を推測しない。空欄では制限しない。他の条件とはANDで併用し、解除・新着・新検索・未描画・出力にも同じ規則を使う。

### Excelで一致箇所を開く

Windowsのデスクトップ版Excelを対象に、xlsx/xlsmのセル・数式・番地付きコメントには「Excelでセルを開く」、位置付き図形には「Excelでアンカーを開く」を置く。行一致・ファイル条件は根拠ごとにボタンを置き、利用者が移動先を選ぶ。シート・セルを特定できない結果はその理由とファイル名から開く方法を示す。通常のファイル名リンクも利用できる。

検索が保持する位置へ移動し、Excel側で文字列を再検索しない。既存ブックを優先して使用する。新しく開く場合は読み取り専用で開き、外部リンクの更新・VBAマクロとイベントを抑止する。セル移動による保存・閉じる・内容や書式の変更は行わない。結合セルは左上の起点に移動し、非表示シート・行列は表示設定を変更せず理由を示す。保護により選択できない場合やExcel未導入・編集中・ファイルやシートの削除・変更・接続先不明では、位置と理由を表示して通常のファイル名リンクを案内する。複数Excelインスタンスの既存ブックへ接続できない場合に別コピーを開かない。

移動中は押したボタンを無効にし、完了・失敗をその箇所に表示する。新検索後に戻った旧操作の応答は現在の結果へ表示しない。実Excelとの互換性・動作確認は[Excelセル移動の確認方針](../test-plans/excel-navigation-test-plan.md)で、自動試験の要求・位置判定と区別する。

### 高度な検索の結果

高度な検索は、同じ検索箇所、Excelの同じ物理行、同じファイルのいずれかで条件を判定する。Excelの同じ行ではセルと検索範囲内の数式にある語句を合わせて1行1件とし、図形や他形式は検索箇所ごとに判定する。ファイル範囲はファイル名と本文を合わせて1ファイル1件とする。結果には成立した正の語句と、各語句が見つかった元の場所・抜粋・強調箇所を並べる。除外語は根拠として表示しない。検索結果の一括出力でも根拠を保持する。

### Excel の周辺セル

高度な検索の `excelRow` 結果からも周辺表を開ける。表に表示される根拠セルを強調する。

Excel のセル・数式一致と位置を取得できた図形一致には「周辺を表示」を置く。開いた時だけ周辺セルを読み、シート名・対象番地、行・列見出し、保存済み値を持つセルを最大5行×5列の表で示す。一致位置を強調し、空欄、非表示の行・列、結合範囲と左上起点を識別できるようにする。図形にアンカーがない場合は取得できない理由をその結果内に示す。表の「前の列」「次の列」で列方向に移動できる。移動後も対象の行を含め、検索条件や結果件数を変更しない。

周辺取得に失敗したときは、その一致箇所の内側に理由を示し、検索結果を消さない。ファイル更新・移動・削除時は再検索を促す。新しい検索が始まった後に前の検索の取得応答が届いても表示しない。値は文書に保存された文字列または数式結果で、数式や条件付き書式は再計算しない。2026-10-03の相談で、列幅・行高・配置・折り返し・結合セルに加え、罫線・塗りつぶし・文字書式の反映を選択した。保存された列幅・行高は画面用に近似し、極端な寸法を抑える。左右/中央/両端配置、上下/中央配置、折り返し、フォント名・サイズ・太字・斜体・下線・取り消し線、RGB文字色・単色RGB塗りつぶし、上下左右の罫線を反映する。結合範囲は表示窓内をrowspan/colspanで表現し、起点が窓外なら保存値と起点の注記を示す。非表示行列は省略せず見出しに表示する。一致セルは書式によらず枠で強調し、表示範囲に入る元の一致文字も黄色で示す。テーマ色・パレット色・濃淡、条件付き書式、数値書式、文字回転・縮小、リッチテキストの部分書式、斜め罫線、柄・グラデーション、画面外の結合部分は完全再現せず、理由を周辺表に示す。書式部品が取得できない場合も標準表示でセル値を残す。通常セル文字列から非表示のふりがなメタデータを除き、検索・抜粋・一致範囲・周辺表で同じ可視文字列を使う。

### 一致箇所の編集

検索終了後、対応する一致箇所の「一致箇所を編集」からダイアログを開く。高度な検索は編集可能な根拠を選び「読み込む」で対象の元行と一致範囲を取得する。パス・行番号・文字コード・前後150文字の文脈を示し、選択した一致文字列だけを入力欄で置き換える。保存またはキャンセル・Escで通常表示へ戻る。読み込み後は検索開始を無効にして編集中の位置情報を維持する。保存・読み込み中のキャンセルを抑え、失敗時は入力を保持して理由と次の操作を示す。

対応形式は検索対象のうちOffice4形式を除く89のテキスト・コード・マークアップ形式（JSON/IPYNB等もテキストとして扱う）。UTF-8（BOM有無）とShift_JISに対応し、対象範囲以外の元バイト・BOM・改行を保持する。追加改行は元ファイルにCRLFが含まれる場合はCRLF、それ以外はLFにする。元の範囲は省略された抜粋ではなく元の行番号と全文内のUnicode文字範囲で特定し、同じ語の別出現を一括置換しない。書式・構造は対象範囲以外を元バイトで保持し、置き換え後の構文の正しさは判定しない。

Office文書、ファイル名一致、位置や元内容を確認できない結果は理由を示して元ファイルを開く操作を案内する。読み取り専用・書き込み権限不足・他アプリの使用中・保存先作成不可・文字コードで表せない文字・外部変更では保存しない。検索時の元バイトのリビジョンと元行を読み込み時に検査し、保存直前は取得時の全バイトと比較する。保存は同じフォルダの作業ファイルを経由し、Windowsでは属性保持とバックアップ付き置換を使う。置換が途中失敗すれば元の復元を試み、復元できなければ保持したバックアップ先を示す。

保存成功時は「保存済み・再検索が必要」をファイルに表示し、そのファイルの旧結果からの再編集・周辺取得を拒否する。表示中の抜粋や件数は検索時点の記録として残し、再検索で更新する。索引は次回検索のファイル情報の変化で更新する。確認方針は [イシュー一括対応](../test-plans/issues-test-plan.md)。

### 一括出力

高度な検索のCSV/TSVには「検索語と根拠」列を追加し、JSON調査記録には各結果の `evidence` と検索条件の `querySpec` を残す。通常検索にも順位理由の列を追加する。一括検索では検索語ID・検索語を追加する。

検索終了後に「現在の絞り込み結果」（初期選択）または「全結果」を指定する。出力件数は現在の選択に応じて表示し、画面に描画されていない結果も含める。該当なし、一部エラー、中断、全体失敗でも、終端通知を受けていれば出力できる。検索中は出力操作を無効にする。

TSVの一括コピーとCSV/TSV保存は、ファイル名、絶対パス、形式、検索箇所、内容区分、場所、抜粋、抜粋省略の有無、一致方式、一致分類をヘッダー付きで出す。抜粋は検索結果の表示用文字列であり、元文書の全文ではない。CSVはUTF-8 BOM付き、TSVはUTF-8とする。タブ・改行・引用符を含む値で列を壊さず、表計算ソフトが数式として扱う先頭文字は無害化する。

JSON調査記録には出力日時、検索ID、検索条件、終了理由、全体集計、出力対象と絞り込み条件、選択された結果、全Issueを保存する。出力対象が絞り込み結果でもIssueは検索全体の記録として残す。保存先は利用者が選ぶ。ダイアログを取り消したときは失敗通知を出さず、書き込みに失敗しても画面の結果を保持する。

## Office追加範囲と一括検索

「注記も検索」「数式文字列も検索」は初期状態でオフ。注記はExcelコメント、PowerPointノート、Wordのヘッダー・フッター・コメントをまとめて指定する。追加結果の場所には数式/コメント/ノート/ヘッダー等の種別を文字で示し、一括コピーと保存にも反映する。

「一括検索」を選ぶと1行1語の入力欄と照合方法を表示する。識別子一致を初期値とし、通常の文字列検索へ切り替えられる。開始前にバックエンドと同じ正規化・重複除去をした件数を示す。識別子として扱えない行は行番号と語を示して通常の文字列検索への変更を案内する。

終端時に入力順の語別一覧（検索語、ファイル数、箇所数、確認状態）を出す。詳細を開くとコアの順位に従うファイル・場所・抜粋を50件ずつ追加する。「語×ファイル一覧」は20語×20ファイルずつ送り、全体は語×ファイルCSV/TSVへ出力できる。画面表示と出力は同じ結果のtermIdを使う。検索途中の絞り込みは通常のファイル一覧と出力対象に適用し、語別一覧は検索全体の集計として保持する。

JSONにはrankings、batchSummary、executionSummaryを保存し、CSV/TSVには順位理由と一括検索時の語ID・語を含める。語×ファイル出力のセルは該当箇所数で、列のファイル集合は選択した全結果/絞り込み結果から作る。全検索の確認状態と出力範囲を別列に示し、全語を残す。未確定な0を不存在として扱わない。

## 進捗とエラー

- 列挙中、検索中、完了、中断、全体失敗を区別する。検索中は処理済みファイル数を表示し、総数が確定しているときだけ分母や割合を表示する。
- 画面上で結果件数とエラー件数を確認できる。1 ファイルの失敗は、対象パスと簡潔な理由を一覧に残す。パスが取得できない列挙エラーも別件として表示する。
- 読み取り・列挙エラーがある場合は進捗表示の直下に赤系の枠と件数付きの折りたたみ欄を示し、展開してエラー種別・対象パス・理由を個別に確認できるようにする。ファイルを開く操作やコピー操作の失敗は画面上の通知で示す。
- 一致箇所のあるファイルで読み取りエラーも起きた場合は、そのファイルの結果をエラー用の色と文字ラベルで示す。エラーの理由は折りたたみ欄でも確認できるようにする。
- 一部のファイルが読めなくても、終端状態は黄系の「完了（一部エラーあり）」とし、結果を保持する。全体失敗は赤系の「全体失敗」で区別する。
- 入力エラーは該当欄の近くに示す。検索開始後の全体失敗は、原因と途中までの結果が残ることを示す。
- 長い検索で結果が増えても画面操作と中断操作ができること。進捗通知の表示頻度は GUI 側で調整してよいが、最終件数は終端通知と一致させる。

## 状態と遷移

| 状態 | 検索 | 中断 | 表示 |
| --- | --- | --- | --- |
| 待機 | 有効 | 無効 | 入力可能。前回の結果は保持してよいが、新規検索を受理した時点で消す。 |
| 列挙・検索中 | 無効 | 有効 | 新しい結果・進捗・エラーを順次追加する。 |
| 中断中 | 無効 | 無効 | 処理停止を待っていることを示す。 |
| 終了 | 有効 | 無効 | 完了・中断・失敗の別と最終件数を示す。結果を保持する。 |

新しい検索を始めたら、その検索 ID に属する通知だけを表示する。前の検索の遅延通知で結果を汚さない。画面を閉じる際に実行中の検索があれば中断を要求し、処理を残したままにしない。

## 操作性

- 入力欄と主要ボタンには見分けられるラベルを付け、キーボードでも検索、中断、各結果のファイルを開く操作と場所のコピーができること。コピーアイコンには操作対象が分かる名前を付ける。
- 処理中・終了時の状態は色だけに頼らず文字でも示す。エラーと入力検証の文言は、次に取れる行動が分かる表現にする。
- パスと場所情報は全文を確認・コピーできる手段を用意する。抜粋を省略する場合も一致語を残し、省略を明示する。
