## 自動確認

`docs-search` を作業ディレクトリとして、自動テストのみの依頼では次を実行する。UI資材stagingとヘッドレスPlaywrightを含む。

```powershell
cargo xtask test
```

Windows配布ビルドまで依頼された場合は、上の入口に代えて `cargo xtask ci` を使う。

| 項目 | 手順 | 期待結果 |
| --- | --- | --- |
| 既存検索の回帰 | 上記の共通ケース、Rustテスト、JS構文確認、ヘッドレスUIを実行 | 既存ケースが通り、検索・件数・中断・出力対象の契約が変わらない |
| 表形式の変換 | `core/src/report.rs` のCSV/TSV変換ケースを実行 | 日本語、空文字、カンマ、引用符、タブ、改行、バックスラッシュで行・列が崩れない。CSVのみBOMが付く |
| 数式の無害化 | `=`, `+`, `-`, `@` と、前に空白を含む値を出力 | 表計算ソフトが数式として扱わない。JSONの原文は変わらない |
| 出力記録の整合 | 全結果・絞り込み結果とIssueのある記録を変換 | 全結果の行数は終端の `resultCount`、Issue数は `issueCount` と一致する。絞り込み結果でも全Issueが残る |

## GUI確認

GUI確認は実施依頼が明示された場合か、実施前の確認が取れた場合に限る。アプリを起動し、検索終了後に次を操作する。

| 項目 | 手順 | 期待結果 |
| --- | --- | --- |
| 全結果と絞り込み | 200ファイルを超える結果を作り、初期選択の絞り込み結果と全結果をそれぞれコピー・保存する | 未描画ファイルも含み、表示された対象件数とデータ行数が一致する。絞り込みのファイル名・拡張子を変えると対象件数も変わる |
| 貼り付け・保存形式 | 日本語、引用符、タブ、改行、数式風の文字列を含む結果をコピーし、CSV/TSVを保存して表計算ソフトで開く | 列がずれず、先頭文字が数式として実行されない。CSVはUTF-8 BOM付き、TSVはUTF-8 |
| 調査記録 | 正常、一部エラー、中断、該当なしの検索後にJSONを保存して内容を見る | 検索条件、終了理由、全体件数、出力対象、選択結果、全Issueが一致する。抜粋省略の有無が分かる |
| 操作状態 | 検索中、終了後、次の検索開始後を確認 | 検索中は出力不可。終了後は0件でも出力可。次の検索開始時は前の結果を出力しない |
| 保存取消しと失敗 | 保存ダイアログを取り消し、書き込みできない場所への保存も試す | 取消しはエラーにならず、失敗は通知される。画面の検索結果と元文書は保持される |

GUIの確認結果は、自動確認の結果と区別して報告する。
