# docs-search v2.0.7

Windows x64 向けの実行ファイルです。対象は[追加機能の実装計画](../plans/implementation-plan.md)のP2・P3です。

## 変更点

- Excelのセル一致とアンカー付き図形一致から、保存済みの周辺セルを最大5行×5列の表で取得できるようにしました。結合範囲、非表示の行・列、遠い列への移動に対応します。
- 高度な検索で「すべて含む」「いずれか含む」「含まない」を指定し、検索箇所、Excelの同じ物理行、ファイル全体の範囲で判定できるようにしました。成立した語句ごとの場所と抜粋を結果・出力へ残します。
- 通常検索は従来どおり入力全体を1語句として扱います。索引を使う場合も、条件の除外判定には対象範囲の全検索単位を使います。
- [実装状況](../reports/implementation-status.md)とP2・P3の確認方針を整備し、専用のCLI受け入れケースをローカルCIに追加しました。

## 確認結果

- PowerShell実装の回帰テストに成功しました。
- ローカルCIで共通バックエンド27ケース、P2の専用CLI 5項目（直接読取・索引初回・索引再利用）、P3の専用CLI 31項目、Rust 18テスト、WASMチェック、Windows実行ファイルのビルドに成功しました。
- P3の専用CLI確認には、行AND/NOT、OR、ファイル名と本文、根拠、入力拒否、読み取りエラー、索引オン/オフとあいまい検索オン/オフを含みます。
- GUIテストは依頼者の指定により実施していません。周辺表の表示・操作、高度な検索の入力と根拠表示、画面からの出力は実機未確認です。
